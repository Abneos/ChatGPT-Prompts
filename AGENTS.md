# Abneos shared agent standards

These are the canonical shared standards for Abneos work. Preserve existing project architecture and apply the relevant standards proportionately.

- Infrastructure, CI/CD, runtime automation and communications: [Infrastructure and CI Cost Standard](standards/ABNEOS_INFRASTRUCTURE_CI_COST_STANDARD.md).
- Launch and material technical changes: [Production Readiness Standard](standards/ABNEOS_PRODUCTION_READINESS_STANDARD.md).
- Customer-facing content and journeys: [Copy and Conversion Standard](standards/ABNEOS_COPY_CONVERSION_STANDARD.md).
- Branded assets: [Brand Identity Standard](standards/ABNEOS_BRAND_IDENTITY_STANDARD.md).

New Abneos repositories must reference the infrastructure and CI cost standard in their AGENTS.md. Tools and agents working elsewhere must explicitly load the applicable standards; this repository's instructions are not automatically inherited across repositories or ChatGPT sessions.
