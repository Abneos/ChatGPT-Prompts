# Social Brand Setup Pack

## Start with selection
Read `references/platforms.json` and `references/delivery.md`. Offer Facebook, Instagram, LinkedIn, TikTok, YouTube, Pinterest, X, Threads, Google Business Profile, WhatsApp Business, Bluesky, Snapchat, Reddit and Nextdoor, plus Other. Treat these as selectable platforms, not a claim of exhaustive coverage. Add other platforms through the same evidence schema.
Use the platforms already requested. Otherwise offer Facebook, Instagram and LinkedIn as a suggested starting selection; ask one compact selection question and continue independent brand research. Do not treat silence as approval to publish.
Select profile setup, launch content, or both. Offer a branded links page as an optional addition. Default to preparation only. Honour user-specified formats; otherwise return chat copy, creating files only when requested or integral to an explicitly requested downloadable pack.

## Establish the brand
Read the supplied website, approved brand guidelines and assets; use connected GitHub for private source files when requested. Prefer current first-party evidence over old examples. Record source URLs/paths and retrieval date. Capture brand name, audience, buyer problem, outcome, actual services, territories, tone, logo, colours, typography, contact details, existing profiles and primary enquiry destination using `assets/brand-brief.json`.
Mark missing information `confirm`; never invent an address, opening hours, credentials, prices, reviews, staff size, legal status or result guarantees. Do not expose personal contact data merely because it occurs in source code. Use only approved public contact details. Label unreserved handles as suggestions. Preserve established accounts; investigate recovery before suggesting replacements.
For Abneos work, apply its current Copy & Conversion Standard at `standards/ABNEOS_COPY_CONVERSION_STANDARD.md` in `Abneos/ChatGPT-Prompts` when accessible (fetch the exact path, rather than relying on code search). Keep output outcome-led, practical and in UK English unless the brand requires otherwise.

## Verify selected platform requirements
Use `references/platforms.json` as a versioned starting register, not an authoritative live database. Before every final pack, verify selected platforms against current official documentation using web search. Open the exact relevant pages; do not rely on search snippets or third-party size charts. Verify text fields, counting convention, image slots, dimensions, file types/size limits, setup URLs, business eligibility and available action buttons.
Record per field/image: source URL, source type, checked date, status, account type, country restrictions and notes. Separate hard platform limits from editorial working targets and recommended export sizes. Never mark a whole platform verified because one specification was checked. If a document cannot be read, retain its previous date and flag unverified; prepare safe draft copy, but do not describe it as upload-ready. If official sources conflict, identify the exact account surface and favour its current help or observed authorised UI, recording the discrepancy.
Re-check after 30 days as a minimum; always check at delivery. Changes to the reusable register require evidence and normal Git saving. A check at runtime need not mutate the installed skill: store a pack-specific snapshot, then propose an evidenced register update. Do not add paid features as standard requirements. Google Business Profile requires eligibility; online-only services may be ineligible. WhatsApp Business and Channels, LinkedIn personal and Company pages, and Facebook personal profiles and Pages are distinct surfaces.

## Create the selected outputs
Generate every required field for the selected account types, avoiding irrelevant fields. Include display name, proposed handle/slug, short bio/tagline, long description where supported, specialties/categories, website/link text, CTA and confirmed logistics. Count the final string including spaces, punctuation and line breaks. Aim close to the requested maximum without padding or distorting brand copy. For emoji/non-BMP text verify the platform counting convention; spreadsheet LEN may differ. Prefer plain text for tightly constrained bios.
Use `scripts/validate_pack.py` on a pack JSON based on `assets/pack-template.json`. Resolve FAIL items; disclose unverified requirements separately from copy length PASS. Do not claim handle availability from syntax checks.
For graphics, reuse approved logos exactly. Use the imagegen skill/tool for requested new raster visuals; do not redraw a logo or manufacture screenshots, people, proof or certifications. Generate separate assets per slot; mechanical export/resize is allowed, but never squeeze a layout to a new aspect ratio. Inspect final images, spelling, dimensions, weight, circular profile crops and mobile/desktop cover crops. Add filenames, dimensions, usage and alt text to an asset manifest. If the requested task includes graphics, prompts alone are incomplete.
For launch content, adapt captions to each platform and add a relevant CTA to a verified destination. Check advertising rules if ads are requested. Do not imply organic copy has been reviewed for paid advertising.

## Deliver and verify
Follow `references/delivery.md` for field coverage and setup guides. Use the Spreadsheets skill for requested workbook creation; include Selection, Brand Brief, Profile Copy, Setup Guide, Graphics, Launch Copy when selected, and Sources & Checks. Add live character count/limit checks, wrapped copy, highlighted confirmations and plain URL text plus clickable links. Render and visually inspect all tabs. Deliver a genuine legacy XLS only if requested, using conversion and signature validation; never rename XLSX to XLS. Package requested downloadable assets and save through the available persistence workflow.
For optional links pages, use the website building workflow and existing repository/domain. Test mobile, keyboard access, link destinations and enquiry routes. Treat account creation, publication, domain deployment, outreach and paid subscriptions as separate actions requiring user authorisation; do not assume pack creation grants these. Proceed when already authorised.
Report what is complete, selections, verification date and material missing information. Do not claim social accounts were created or assets uploaded unless verified.
