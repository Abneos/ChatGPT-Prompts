# Delivery contract

## Field coverage
Facebook Page: name, suggested username/public URL, bio, About, category, CTA, website, approved phone/email, address if public and real, service areas and actual hours.
Instagram professional profile: username, searchable name, vertical bio, external URL/title, category and supported contact/action buttons.
LinkedIn Company Page: name, proposed slug, tagline, description, up to 20 relevant specialties if current UI supports them, industry, website, actual legal/headcount/location details; do not confuse a Company Page with a founder profile.
Other platforms: derive exact supported fields from the selected account surface's current official documentation; capture them in the delivery snapshot before writing. Do not copy Facebook fields into every platform.

## Non-technical setup guide
Include numbered steps, exact clickable setup/help links, which copy row to paste, which image to upload, expected result and fallback if a setting is unavailable. Start by checking for an existing page; preserve ownership and access roles. Cover creating/selecting the correct business surface, category, copy, imagery, link/CTA, contact visibility, two-factor authentication and viewing as a visitor. End with crop checks, clickable destination checks and enquiry notification testing. Never share passwords, publish a private address by default or pay for a premium account without instruction.

## Verification snapshot
Store field/image evidence at item level: platform, account type, region, source URL, checked date, hard limit or recommended size, counting convention, status and caveats. Make unresolved requirements visible in Sources & Checks and the handover. Never refresh the date without checking the fact.

## Service packaging
Support one platform or a selected bundle. Profile setup, launch content and links page are independent scope options. Record revisions requested and actual deliverables; do not promise ongoing monitoring, pricing, turnaround or performance unless agreed. Preserve client brand separation. Example brand assets and contact details are never defaults for other clients.
